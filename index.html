Projects

Exchange Simulator

TypeScript, React, Vitest
Real-time exchange simulator for demonstrating adverse selection and market microstructure. Features a price-time priority matching engine, adaptive market maker that widens spreads when detecting informed flow, and configurable trader agents (informed vs. noise). Built with seeded RNG for deterministic, reproducible experiments. The project visualizes why bid-ask spreads exist and how market makers survive toxic order flow.
GitHub Live Demo

Quant Toolkit

Python, FastAPI, pandas, numpy, scipy, arch
Python library and REST API for quantitative finance research. Includes data fetching from Yahoo Finance and Alpha Vantage, an event-driven backtester with SMA/momentum/RSI strategies, risk analysis (VaR/CVaR via historical, parametric, and Cornish-Fisher methods), and GARCH(1,1) volatility estimation. Designed to integrate with the Exchange Simulator by exporting volatility parameters as JSON.
GitHub

Quant Engine

C++20, CMake, Catch2, Docker, PostgreSQL
C++20 research engine for quantitative analysis. Features deterministic backtesting with configurable strategies, Black-Scholes option pricing with Greeks calculation, and full Docker + PostgreSQL persistence for storing backtest runs. Built with CMake and tested with Catch2. CLI interface for running backtests on historical CSV data.
