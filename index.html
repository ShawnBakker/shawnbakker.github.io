Featured Project

QUANT-ENGINE

C++20 Quantitative Backtesting + Research System

Quant-Engine is a C++20 quantitative research engine built with a focus on determinism, performance, and clean system boundaries. It includes a reusable C++ core, a CLI for fast experimentation, and a Docker-backed API + Postgres database for persisting runs and metrics.

  • ▸ C++20 core using STL + Boost (explicit costs, minimal abstraction)
  • ▸ Deterministic backtesting (SMA crossover, transaction costs, PnL)
  • ▸ Black–Scholes options pricing + Greeks
  • ▸ Dockerized API + Postgres persistence (runs + metrics)
  • ▸ Catch2 unit tests + reproducible CMake builds

DEMO

Build, test, run, persist, and query — end to end

Step 1 — Build + Test (Windows)

Compiles the C++20 engine with CMake and runs the Catch2 test suite.

cmake -S cpp/engine -B build_x64 -G "Visual Studio 17 2022" -A x64 cmake --build build_x64 --config Release ctest --test-dir build_x64 -C Release --output-on-failure

Step 2 — Start API + Postgres (Docker)

Spins up the Dockerized API and Postgres database, verifies health endpoint.

docker compose up -d --build curl.exe http://127.0.0.1:8787/health

Expected Output:

{"ok":true}

Step 3 — Run a Backtest (Records to API)

Executes backtest using sample data. CLI records run metadata and metrics to API.

.\build_x64\Release\qe_cli.exe backtest --data .\data\sample.csv --out .\out

Step 4 — Query Stored Runs

Retrieves all stored backtest runs from Postgres with full metadata.

curl.exe http://127.0.0.1:8787/runs
