Featured Project

Low-Latency Order Execution Engine

C++20, std::atomic, std::counting_semaphore, CMake
Lock-free SPSC queue built from scratch using acquire/release memory ordering with alignas(64) cache-line padding to prevent false sharing. Benchmarked at 118M ops/sec on a power-of-2 ring buffer. MPMC queue based on Vyukov's design with per-slot sequence numbers and CAS retry loops for ABA prevention. Stress-tested under extreme contention (100 producers, 100 consumers, 10K messages each, zero lost) to validate correctness under conditions modeled after market-open bursts.
Price-time priority matching engine with O(1) cancel via order index and partial fill support. Measured 1.0 microsecond p50, 1.9 microsecond p99 order-to-fill latency across 100K orders through the in-memory processing pipeline. Deadlock prevention enforced through global lock ordering (OrderBook before PositionBook) with a debug-mode runtime validator using thread_local tracking. Compiles to zero-cost no-ops in Release builds.
11 tests (8 unit, 3 stress including 50-thread deadlock torture) with benchmarks and ThreadSanitizer-clean builds. Every memory ordering choice documented with inline rationale.
