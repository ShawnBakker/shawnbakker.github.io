Featured Project

MARKET MICROSTRUCTURE
SIMULATOR

Real-Time Exchange Simulation for Adverse Selection Analysis

Built a real-time exchange simulator to demonstrate why bid-ask spreads exist and how market makers adapt to toxic order flow. It's got a price-time priority matching engine, an adaptive market maker that widens quotes when it detects informed flow, and configurable trader agents. Crank the toxicity and watch spreads blow out — it's the Glosten-Milgrom model playing out in code.

  • ▸ Matching engine with price-time priority (same logic as real exchanges)
  • ▸ Adaptive market maker that detects toxicity and widens spreads to survive
  • ▸ Informed traders exploit stale quotes, noise traders add realistic volume
  • ▸ Seeded RNG for deterministic, reproducible experiments
  • ▸ React dashboard with live P&L, spread, and order book visualization

Step 1 — Build + Test (Windows)

Compiles the C++20 engine with CMake and runs the Catch2 test suite.

cmake -S cpp/engine -B build_x64 -G "Visual Studio 17 2022" -A x64 cmake --build build_x64 --config Release ctest --test-dir build_x64 -C Release --output-on-failure

Step 2 — Start API + Postgres (Docker)

Spins up the Dockerized API and Postgres database, verifies health endpoint.

docker compose up -d --build curl.exe http://127.0.0.1:8787/health

Expected Output:

{"ok":true}

Step 3 — Run a Backtest (Records to API)

Executes backtest using sample data. CLI records run metadata and metrics to API.

.\build_x64\Release\qe_cli.exe backtest --data .\data\sample.csv --out .\out

Step 4 — Query Stored Runs

Retrieves all stored backtest runs from Postgres with full metadata.

curl.exe http://127.0.0.1:8787/runs
